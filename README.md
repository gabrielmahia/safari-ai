# 🚌 Safari AI — Kenya Transport & Logistics in Swahili
Matatu routes, SGR booking, NTSA services, and road safety — all in Swahili.
[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://safariAI.streamlit.app)
## Features
- 🗺️ Route planning (matatu, bus, SGR, ferry)
- 🚂 SGR tickets and schedules
- 🚗 NTSA services (license, registration, fines)
- ⛽ Daily fuel prices (EPRA)
## Data Sources: SGR (krc.co.ke) | NTSA (ntsa.go.ke) | EPRA
